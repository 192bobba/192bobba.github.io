Accès GitHub – charger n'importe quel ticker

Pour un ticker qui n'est pas encore copié (action, ETF, indice, crypto, devise…), l'application demande à votre dépôt GitHub de le copier depuis Yahoo Finance : 30 à 60 secondes la première fois, puis c'est instantané. Il faut pour cela un jeton d'accès GitHub, à créer une seule fois :

  1. Touchez « Créer le jeton sur GitHub » ci-dessous (connectez-vous si besoin).
  2. Token name : Monte Carlo iPad. Expiration : la durée la plus longue proposée.
  3. Repository access : « Only select repositories », puis choisissez 192bobba/192bobba.github.io.
  4. Permissions : ajoutez Actions avec « Read and write » et Contents avec « Read-only ».
  5. Touchez « Generate token », copiez le jeton (il commence par github_pat_), revenez ici et collez-le.
